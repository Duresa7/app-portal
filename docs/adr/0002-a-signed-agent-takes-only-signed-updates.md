# A signed agent takes only updates signed by its own publisher

The agent runs every update MSI as SYSTEM. Its SHA-256 check compares the MSI with the `SHA256SUMS` of the same release, which catches corruption and a swapped file on the way down, but not anybody who can change release assets: a leaked token, a compromised workflow, or an `updateRepository` pointed somewhere hostile replaces both files together. From M6-03 onwards the agent also checks the MSI's Authenticode signature before it runs or stages it (`UpdateSignaturePolicy`).

The trust anchor is the running agent's own signature. When the agent is validly signed, the MSI must be validly signed with the same certificate CN and O; otherwise the update is refused, and the reason is written to `update.json`. When the agent is not validly signed, which covers 0.8.0 and every build before the first signed release, fleets built by their owners, and test-signed rehearsals, the MSI is checked by its SHA-256 alone, as before. Nothing is stranded: an unsigned agent takes the first signed release, and a fleet is moved back to unsigned builds by deploying an unsigned MSI once by hand.

Two alternatives were rejected. Pinning the signing certificate's thumbprint breaks at every certificate renewal, which for SignPath Foundation is routine, and every fleet would refuse the first release after it. A publisher name written into the agent breaks self-hosters who sign with their own certificate, and makes the check useless to them.

The limit is that the publisher SignPath Foundation is shared by every project the foundation signs. The check tells a foundation-signed MSI from an unsigned or foreign one; it does not tell App Portal from another foundation-signed product. Getting past it takes release write access and a malicious MSI the foundation signed. Checking the MSI's `UpgradeCode` as well is possible later hardening and is not part of this decision. A change of CN or O at a foundation certificate renewal would make signed agents refuse the next release until it is deployed by hand; that is accepted as the price of not pinning a thumbprint.
